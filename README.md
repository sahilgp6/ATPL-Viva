# ATPL Viva: Nav & Radio

Offline question bank for the DGCA ATPL combined Nav/Radio viva, built from the merged ATPL Viva Reference.

- Open the GitHub Pages URL once while online, then "Add to Home Screen". It works fully offline after that.
- Progress is saved on the device only. Use Progress, Export to back it up or move it to another device.
- Grading is instant and offline: multiple choice, numbers, ordering and matching are marked automatically; "say it" answers are checked against key points, and you can tap any key point to correct the mark.
